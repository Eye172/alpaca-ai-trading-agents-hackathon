# PLAN-MAX — пакет апгрейдов поверх PLAN.md

> Цель: не «хороший проект», а максимум достижимого за 7 дней силами двух человек.
> Честно: гарантии победы нет — P&L частично лотерея, судейство финально.
> Но можно сделать так, чтобы по 4 из 5 критериев мы были объективно сильнейшими,
> а по пятому (P&L) — в верхней группе с вероятностью ~80%.

## 0. Где мой же базовый план слабее максимума

Самокритика PLAN.md — четыре зазора:

| # | Слабость базового плана | Чем закрываем |
|---|---|---|
| 1 | Утверждения про риск-гейты **декларативные**: «гейт защищает» — сказано, не измерено | **Живая абляция**: параллельные counterfactual-книги показывают цену каждого решения в долларах |
| 2 | Воспроизводимость = «числа сходятся». Vega уже сделала это | **Детерминированный реплей всей недели**: агент — чистая функция от входов, любой может перепрогнать неделю бит-в-бит |
| 3 | «AI-часть» тонковата: два голоса LLM — и всё | **Торговый деск из ролей** с записанными совещаниями + ночная саморефлексия с ограниченной самонастройкой |
| 4 | P&L-движок один (VRP carry) — одна ставка на один режим рынка | **Три источника теты** с разными профилями + риск-бюджет, который агент «зарабатывает» |

## 1. TIER 1 — решающие апгрейды (делаем обязательно)

### 1.1. Живая абляция — «мы измерили цену каждого решения» ★★★

Самая сильная идея всего пакета. Vega опубликовала **одно** измеренное решение
(«стоп срабатывает на 91% путей и роняет нашу вероятность top-3 с 15.9% до 6.2%»).
Мы публикуем **непрерывное измерение всех решений**.

Параллельно с боевой книгой ведём три **теневые книги** на тех же входных данных:

| Книга | Что это | Что доказывает |
|---|---|---|
| **SHADOW-NOGATES** | Та же стратегия, но риск-гейты отключены (симуляция на реальных котировках) | Сколько долларов сэкономили гейты |
| **SHADOW-NOHEDGE** | Core без рукава Hedge | Сколько стоит/приносит хедж |
| **BASELINE-NAIVE** | «LLM читает новости → покупает коллы» — то, что построят 200 команд. Гоняется на **отдельном реальном paper-счёте** (Alpaca разрешает несколько) | Наш агент против типового решения хакатона, живой P&L против живого P&L |

На дашборде — 4 кривые эквити рядом. В видео это один слайд, который
хоронит большинство конкурентов: **«вот наша книга, вот она же без мозгов,
вот то, что сдали остальные»**.

Реализация дешёвая: теневые книги — это тот же `payoff.py` + журнал, без отправки
ордеров (кроме BASELINE — он реально торгует на втором dev-счёте). BASELINE прост
по определению — его пишем за 2 часа.

> ⚠️ На судейство подаётся **только** основной свежий счёт. Остальные счета —
> dev/эксперименты, это разрешено («use any paper account during development»).

### 1.2. Детерминированный реплей недели ★★★

Каждый тик сохраняет **полный вход**: снапшот чейна, позиции, промпты, ответы
моделей (записанные, с хешами). Команда:

```
make replay
```

перепрогоняет всю неделю оффлайн и воспроизводит **каждое решение бит-в-бит**.
Честная формулировка (важно, LLM недетерминированы): *«пайплайн детерминирован
при записанных голосах моделей; голоса записаны и захешированы в момент получения»*.

Это сильнее, чем «31 число сходится»: у нас сходится **вся траектория агента**.
Плюс это бесплатный отладчик: любой баг недели воспроизводим локально.

### 1.3. Glass-box дашборд + Judge Mode ★★★

Дашборд — первое, что откроют судьи. Максимум:

- **Каждая сделка кликабельна** → полная цепочка решения: хеш снапшота → голоса
  двух моделей (полный текст) → результат каждого из 16 гейтов → поверхность
  выплат до/после → ордер → филл
- **Каждый отказ тоже кликабелен** — отказы не менее важны, чем сделки
- **Лента решений в реальном времени** — видно, что агент живёт прямо сейчас,
  во время судейства
- **Judge Mode**: ссылка `?judge=1` — режим с аннотациями «что смотреть»:
  подписи к каждому блоку, ссылки на строки кода в GitHub
- 4 кривые эквити (боевая + 3 абляции) на главном экране

### 1.4. Заработанный риск-бюджет ★★

Классическое правило проп-деска, которое никто на хакатоне не сделает:

```
risk_budget_today = BASE (1.5% эквити) + 0.5 × max(0, realized_pnl)
```

Агент **начинает осторожно и наращивает риск только из реализованной прибыли**.
Просадка ранняя → бюджет сжимается сам. Это:
- защищает кривую эквити в первые, самые опасные дни
- даёт красивую формулировку: *«агент зарабатывает право рисковать»*
- разгоняет P&L во второй половине недели, если всё идёт хорошо — ровно
  когда судьи смотрят

## 2. TIER 2 — глубина и отрыв

### 2.1. Третий источник теты: двойные календари

Находка из ресерча: короткая нога **11 сентября**, длинная **18 сентября** —
**обе экспирации после дедлайна 4 сентября**, гейт «ноль экспираций в окне»
не нарушен, а тета короткой ноги (11 DTE) распадается почти вдвое быстрее.

Селектор выбирает конструкцию по term structure:

| Сигнал | Конструкция |
|---|---|
| Front IV дорога против back | Двойной календарь (put + call calendar) |
| Skew симметричен, IV дорога везде | Iron condor |
| Put skew особенно дорог | Put credit spread |

Три семейства + рукав Hedge = богатая книга, риск-движку есть что балансировать,
а в write-up — таблица «почему выбрана каждая конструкция».

### 2.2. Торговый деск из ролей + утреннее совещание ★★

Вместо «двух голосов» — **деск с ролями и записанным совещанием**:

| Роль | Модель | Задача |
|---|---|---|
| **Vol Analyst** | Claude | Дорога ли волатильность? VRP, term structure, skew |
| **Risk Officer** | Claude, отдельный промпт | **Адвокат дьявола**: обязан атаковать предложение аналитика |
| **News Vetoer** | Featherless (open model, дёшево, часто) | Каждый тик сканирует новости: есть ли причина НЕ торговать сегодня |
| **Second Opinion** | Featherless (модель побольше) | Независимая оценка VRP; расхождение с Claude → размер ×0.5 |

**Каждое утро в 09:35 ET деск проводит «совещание»** — структурированный
обмен, транскрипт публикуется на дашборде и становится дневным постом
(соц-трек кормится сам). Судья читает, как Risk Officer вчера зарубил сделку —
это лучшая демонстрация «AI-агента», какая возможна.

**Ночная саморефлексия:** после закрытия агент пишет ретро — что сработало,
что нет — и может подкрутить параметры **только в зашитых границах**
(дельта короткого страйка 0.12–0.22, порог спреда 5–10%...). Каждое изменение
логируется с обоснованием. «Агент, который учится за неделю» + полный аудит.

### 2.3. Экосистемная игра — судьи из Alpaca ★★

Судят Chief Brokerage Officer, PM и Team Lead Trading API. Им важен их продукт:

- Репозиторий оформляем как **референсную архитектуру**: «autonomous options
  agent on Alpaca — reference implementation» с переиспользуемыми модулями
- **Контрибуция upstream**: за неделю работы с MCP-сервером и CLI мы почти
  наверняка найдём шероховатость → issue или PR в `alpacahq/alpaca-mcp-server` /
  `alpacahq/cli`. Даже docs-PR — сигнал. Найдём реальный баг — золото
- Написать и приложить **новый SKILL.md** в формате `alpaca-skills`:
  «mleg options via CLI» — навыка про мультиноговые ордера у них нет
- Файл `API-FEEDBACK.md`: что было отлично, что не хватило (например, флагов
  mleg в `order submit`). Вендоры это обожают

### 2.4. Двухуровневая экономика моделей (Featherless по-настоящему)

Партнёрский приз требует **реальной** интеграции. Максимум — осмысленная
архитектурная роль, не галочка:

- **Featherless (дёшево, часто):** новостное вето каждый тик, классификация
  режима рынка, черновики соцпостов
- **Claude (дорого, редко):** глубокий анализ на утреннем совещании,
  ночная рефлексия

В write-up: *«двухуровневая экономика инференса: открытые модели для
высокочастотных задач, frontier-модель для глубоких решений»*. Это зрелый
продакшн-паттерн, и он документируется с числами (сколько вызовов, сколько стоило).

### 2.5. Агент ведёт «build in public» сам

Каждый вечер агент **сам пишет черновик поста** по итогам дня (данные из
журнала: сделки, отказы, P&L, урок дня). Человек только вычитывает и постит.
В постах это прямо сказано: «черновик написан самим агентом». Соц-трек
($500 + подписки, 2 команды, почти пустой) закрывается почти без наших усилий,
и это само по себе фича проекта.

## 3. TIER 3 — страховки (дёшево, обязательно)

| Что | Как |
|---|---|
| **Watchdog** | Если heartbeat молчит >90 мин в торговые часы → Telegram-алерт нам. Не флэттим по сбою (сбой инфры ≠ рыночный риск) |
| **Сверка состояния** | Каждый тик: позиции берутся из брокера, не из своей БД. Расхождение → алерт + пауза новых ордеров |
| **Двойной cron** | GitHub Actions + локальный fallback (Task Scheduler). Один упал — второй жив |
| **Property-based тесты гейтов** | `hypothesis`: генерируем случайные книги → инварианты гейтов держатся всегда |
| **Страховка сабмита** | Черновик полностью заполнен к дню 6; видео залито заранее; account ID проверен трижды; скриншоты всего заархивированы |
| **Конкурентная разведка** | День 5–6: читаем чужие сабмиты на платформе, затачиваем позиционирование видео против реального поля |

Судейские критерии и наша позиция после апгрейдов:

| Критерий | Наша позиция | Уверенность |
|---|---|---|
| Technology Implementation | MCP + CLI + mleg + греки + calendars + upstream-PR. Потолок того, что можно показать | **Контролируем** |
| Creativity & Originality | Деск с ролями, абляции, заработанный бюджет, реплей. Не «ещё один сигнальный бот» | **Контролируем** |
| Presentation & Execution | Glass-box + Judge Mode + видео с абляционным слайдом + реплей вживую | **Контролируем** |
| Social Engagement | Агент сам пишет посты + транскрипты совещаний = контент без усилий | **Контролируем** |
| P&L Performance | P(плюс) ≈ 80%; заработанный бюджет разгоняет хвост недели; три источника теты сглаживают | **Частично** — остаток лотерея |

Единственный сценарий поражения по существу: сильный обвал рынка в окне —
и тогда наш Hedge + гейты дают **лучшую из плохих** кривых, а абляция
показывает, что без гейтов было бы хуже. Даже плохой рынок работает на наш нарратив.

## 5. Линия отсечения — что резать, если горим по времени

Приоритет при нехватке времени (сверху — неприкосновенно):

1. Ядро: Core + Hedge + 16 гейтов + payoff simulator ← **не режется никогда**
2. Реплей + reconcile ← не режется: это наш ответ Vega
3. Glass-box дашборд (можно упростить до Streamlit)
4. Абляция SHADOW-NOGATES + BASELINE-NAIVE (SHADOW-NOHEDGE — первая под нож)
5. Заработанный риск-бюджет (маленький, но режется безболезненно)
6. Утренние совещания (можно сократить до 1 обмена репликами)
7. Календари ← режем первыми: два семейства конструкций уже достаточно
8. Upstream-PR и SKILL.md ← если найдётся время/баг

## 7. Формулировки для сабмита (обновлённые)

**Одно предложение:**
> Автономный опционный деск на Alpaca: LLM-роли спорят на утреннем совещании,
> детерминированный риск-движок держит право вето по всей книге, каждое решение
> недели воспроизводимо одной командой — и мы измерили в долларах цену каждого
> своего архитектурного решения, гоняя рядом версии агента без мозгов.

**Три цифры, которые запомнят судьи (заполним реальными):**
1. «Гейты отклонили N ордеров и сэкономили $X против книги без гейтов»
2. «Наш агент против наивного LLM-трейдера: +X% против −Y% на живых счетах»
3. «make replay: вся неделя воспроизводится бит-в-бит, 0 расхождений»
